## Implemented claim

move selector. One admitted model operation receives the exact learner request,
retained steering, a bounded immutable Learning Context cut, the final
capability surface, and owner-native lazy reads. The learner-visible Assistant
action is the move; no candidate-ranking record, `selectedCandidate`, purpose
table, selector Agent, scheduler, controller, activity owner, or second runtime
was added.

The implementation makes one representation and migration repair so a legal
cross-owner situation can reach that ordinary Agent:

```text
complete canonical cut, policy 6, catalog 6
-> lossless model-facing renderer 7 projection
-> exact stored canonical/rendered bytes and fingerprints
-> ordinary released-v1 provider/tool/Assistant/Turn chain

existing v1-v6 stored cuts
-> frozen validators/renderers only
-> byte-identical replay without current owner reads
```

The fixed bounds remain 32,768 canonical bytes and 16,384 rendered bytes. A
truly irreducible overflow still fails before provider transport. No learning
owner schema or lifecycle changed.
