# 执行计划（exec-plans）

执行计划是一等工件：跨多个任务的复杂工作在此成文，带进度与决策日志，并随代码一起进仓库。约定来自 [repo harness 实践](../adr/0006-adopt-repo-harness-practices.md)。

## 目录

- `active/` — 进行中的执行计划，文件名 `YYYY-MM-DD-<slug>.md`。
- `completed/` — 已完成或已废弃的执行计划归档，保留决策记录。

## 约定

- 小改动不需要执行计划，直接走 PR；跨多个任务或需要留下决策轨迹的工作才开计划。
- 计划包含固定小节：目的、任务分解、决策日志、进度日志。
- 计划完成时归档到 `completed/`，在正文补充最终状态；不删除历史。
- 计划引用的仓库文件一律使用相对链接，保证在仓库内可导航。
