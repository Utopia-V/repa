# Triage 标签

Skills 使用五种标准 triage 角色。本文件把这些角色映射到本仓库 issue tracker 中的实际标签。

| `mattpocock/skills` 中的角色 | 本仓库标签             | 含义                           |
| ---------------------------- | ---------------------- | ------------------------------ |
| `needs-triage`               | `needs-triage`         | 维护者尚需评估该 Issue         |
| `needs-info`                 | `needs-info`           | 正在等待报告者补充信息         |
| `ready-for-agent`            | `ready-for-agent`      | 规格完整，可由 Agent 独立处理  |
| `ready-for-human`            | `ready-for-human`      | 需要由人实施                   |
| `wontfix`                    | `wontfix`              | 不再处理                       |

Skill 提到某个角色时，例如“应用可由 Agent 独立处理的 triage 标签”，使用表中对应的实际标签。

如果仓库以后采用其他标签词汇，只修改右侧“本仓库标签”列。
