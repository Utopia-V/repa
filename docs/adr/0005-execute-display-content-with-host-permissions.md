# 按宿主授权执行展示内容

本记录约定目标设计；当前实现范围与运行方式见 [README](../../README.md#运行现有-tui)。

插件提供展示能力，Agent 或工具生成的页面、图表作为内容交给相应渲染器。Markdown、公式、图片与结构化图表由可信组件显示；需要脚本的交互内容默认在独立展示环境中执行。安装启用的插件代码属于应用的运行组成，生成文件本身不自动取得插件身份与权限。保持这个边界，使交互内容可以持续产生，而应用能力的启用仍由宿主拥有。

每个展示实例取得明确提供的数据、资源和动作，例如本次实验数据、打开来源、提交结果或请求解释。普通实例不直接取得完整 Repa 客户端；读取额外材料或执行其他操作时，通过宿主按当前授权处理。宿主检查消息来源、参数和目标范围，页面提供的文字、数值及权限声明保留为该页面的内容或输出，不自行升级为用户指令与授权。

缩放、拖动、调参和动画在展示内部完成。保存结果和提交练习通过宿主动作写入已授权目标，向 Agent 提问时把当前状态组成可见请求，已有授权覆盖的动作直接执行。页面计算结果与学习判断保留各自含义，普通交互不持续触发模型请求。

用户可以显式选择 Full Access，放宽相应范围的数据、工具、网络或其他执行权限。宿主明确显示作用范围，按当前授权决定实际可用能力；权限放宽不改变内容来源、操作记录和生命周期的含义，也不把页面自身的权限声明视为授权。

会话中的展示产物保留重新打开所需的内容和输入数据，这些数据随会话持久保存，可重建的部分才作为缓存管理。持续维护的结果保存为文档并进入内容引用、修订与编辑体系，同时保留文档必需的资源，其生命周期独立于原会话的清理；缩放位置、动画进度等交互状态由前端按需保存。重新打开历史产物时按当前授权建立实例，旧声明不恢复已失效的权限，重新运行计算或 Agent 调用形成可识别的新操作。

渲染器须声明并实际满足所需的执行条件，分别处理宿主访问隔离、资源加载、对外连接、导航与消息桥接。无法满足条件的前端提供静态结果或源码视图，并说明相应交互能力不可用；不通过自动放宽权限继续执行。具体接入由真实运行环境验证。可优先评估复用 [MCP Apps 的 AppBridge 等 SDK 模块](https://github.com/modelcontextprotocol/ext-apps#using-the-sdk)，其[隔离与通信规范](https://github.com/modelcontextprotocol/ext-apps/blob/main/specification/2026-01-26/apps.mdx#sandbox-proxy)作为接入依据；具体渲染宿主仍需集成与验证。
