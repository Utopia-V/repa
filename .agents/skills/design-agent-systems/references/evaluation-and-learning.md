# 评测、经验沉淀与自我驱动

在具体问题涉及 eval、轨迹归因、长期沉淀、踩坑、自我改进、自我驱动或停止条件时读取本参考。它约束判断和证据，不要求建立统一评测平台、经验 Ledger 或自动更新流水线。

## 保存因果信息的评测

将以下问题分开：

| 层 | 判断内容 | 适合的证据 |
| --- | --- | --- |
| 结果 | 环境状态、工件或答案是否满足父结果 | 确定性检查、原始来源、真实环境、受保护 oracle |
| 过程 | 权限、数据流、动作顺序和约束是否满足 | 轨迹、工具事件、状态转换和审计记录 |
| 首错 | 第一个改变后续可达状态的观察或决定在哪里 | 与正确前缀、对照轨迹或人工植入错误比较 |
| 质量 | 开放问题的解释、帮助程度、风格或取舍是否合适 | 明确 rubric、配对判断、用户或独立 reviewer |

总分适合选择候选；归因需要保留任务、输入与来源版本、Environment、Model/Harness 配置、动作轨迹和验证器身份。一次最终成功可能掩盖越权或偶然绕过，一次最终失败可能只是早期首错的远端结果。

验证器与修改者的责任可以由同一主体在不同时刻承担，但修改候选不能同时改变批准自己的 oracle、回归集、安全门或接受阈值。自写测试是回归证据，不自动成为独立接受证据。

## 经验的成熟度

| 产物 | 保存什么 | 何时升级 |
| --- | --- | --- |
| 原始观察 | 实际输入、动作、结果和定位 | 保持不可被后来解释重写 |
| 根因假设 | 已建立因果、竞争解释和待裁决缺口 | 有能区分解释的 probe 或新证据 |
| 可复用认识 | 带范围、证据、反例和失效条件的解释 | 在相似场景迁移，且不在反例中误触发 |
| 操作指令 | 会稳定改变以后动作的规则 | 拥有者接受，且保留原有正确行为 |
| 可执行能力 | Skill、工作流、工具或程序 | 独立回放、回归、安全与回滚边界通过 |

模型总结只改变可读性，不改变证据等级。网页、邮件、工具输出或其摘要中的指令不能因为“有用”而直接升级为 Skill 或程序。

## 踩坑如何防止重犯

一条长期踩坑至少回答：

- 适用于哪个目标、任务族、版本、环境或材料；
- 当时尝试了什么，实际结果由什么证据定位；
- 根因是已建立、仍有竞争解释，还是只有待验证猜测；
- 下次先检查什么、避开什么、失败后回到哪个可靠状态；
- 哪个 API、规则、版本或新证据变化会让它失效；
- 原始 Session、Git revision、run record、来源或验证结果在哪里。

原始失败留在实际历史或 run record；仍在竞争的解释留在当前调查；跨场景稳定结论进入已有知识或规则 owner；当前工作只取回会改变本次判断的部分。一次偶发异常、模型猜测和可重建叙述不应升级为永久经验。

用三种场景检查沉淀是否有效：一个应该复用的相似场景、一个不应触发的反例，以及新证据要求修订或退役的场景。只追加而不允许遗忘会制造负迁移。

## 更新能力与受益能力

端到端结果没有改善时，沿链路定位：

`经验是否值得更新 → 更新是否正确 → 是否存到正确 owner → 能否在相关场景激活 → 激活后能否遵循 → 是否迁移 → 是否保留旧能力`

知识或 Skill 正确但没有激活，是发现或路由问题；已经激活但没有遵循，是 Model/Harness 执行问题；持续触发却退化，可能是内容、范围或冲突问题。知识库条目数量、反思文本长度和一次成功案例都不能单独证明系统学会了。

## 自我驱动与停止

自我驱动从父结果、当前事实、证据缺口和可用动作之间推导。Agent 可以：

- 选择最便宜且能改变决定的已授权观察；
- 提出范围局部、可反驳、可回滚的修改；
- 用负结果关闭已经被证据否定的路径；
- 在外部条件未满足时保留恢复入口并停止。

目标、价值取舍、外部授权、接受标准和事实终审仍由相应 owner 持有。在线执行与离线整理可以作为实现模式：在线完成任务并保留证据，离线形成候选更新，再由独立验证决定是否发布；关键语义是证据、提案和批准保持区别，不是必须部署两个服务。

当下一步依赖用户判断、新材料、外部资源或接收方结果，且继续本地工作不能改变判断时，合法结果是说明缺口和恢复条件后停止。新增文档、重复实验、无关重构或更多 Agent 不能凭活动量证明进展。

## 一手来源与案例入口

- [`ai-agent-book` 第 7 章：Agent 的评估](https://github.com/bojieli/ai-agent-book/blob/a18a5f764589396d903d8faeaed205489a21bf4b/book/chapter7.md)和[第 9 章：Agent 的持续进化](https://github.com/bojieli/ai-agent-book/blob/a18a5f764589396d903d8faeaed205489a21bf4b/book/chapter9.md)用于发现问题；书中结论仍需一手来源或实际场景核验。
- [Reflexion: Language Agents with Verbal Reinforcement Learning](https://arxiv.org/abs/2303.11366)只支持其特定实验条件下语言反馈改善后续尝试，不证明反思天然正确或可以自动发布。
- [`τ²-bench`](https://github.com/sierra-research/tau2-bench)与 [`SWE-bench`](https://github.com/SWE-bench/SWE-bench)展示任务、工具、Environment、轨迹和可执行结果的组合评测；其指标和分数不能直接成为其他产品的接受标准。
