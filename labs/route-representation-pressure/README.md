# Broad-route representation pressure lab

Date: 2026-07-12

Status: Completed. Six executable cases passed with 29 assertions.

## Decision under pressure

The lab asks whether the first durable course route can remain an ordered list
with one current pointer, or whether current product queries require an ordered
hierarchy, sparse typed relations, revision-bound material alignment, and
separate learner/agenda overlays.

The test uses information collisions rather than schema aesthetics. Two
learning situations are deliberately projected to the same list-and-pointer
state while requiring different correct answers. If such a collision exists,
no later algorithm or larger model can recover the missing distinction from
that state.

## Frozen cases

1. nested versus shallow course structure with the same flattened order;
2. prerequisite detour/rejoin versus a genuine route rollback;
3. a deadline jump versus genuine advancement of the broad route;
4. alternative branches versus sequential authored exposition;
5. accepted versus merely proposed prerequisite relations;
6. current versus stale material ranges with the same unversioned selector;
7. conflicting material order without rewriting course order; and
8. one learner error creating a personal revisit without editing the course.

## Promotion rule

- If the list and one pointer distinguish every required answer, retain them.
- If hierarchy alone resolves the collisions, promote only hierarchy.
- If a typed relation, revision binding, or separate overlay is the only fact
  that resolves a collision, promote that semantic distinction but not the
  accidental TypeScript shape used by this lab.
- This lab cannot earn a graph database, a universal relation ontology, an
  automatic prerequisite extractor, or a production table layout.

## Result

The list-and-pointer baseline has real information collisions in every frozen
category. The candidate distinctions resolved them without putting learner or
agenda facts into the shared course view.

Promoted as representation requirements:

- authored containment/order must survive as an ordered hierarchy;
- broad route anchor, active focus, and temporary rejoin are distinct facts;
- a relation that can constrain action needs a type, acceptance state, and
  source rather than being inferred from nearby authored order;
- material alignment is many-to-many and bound to an artifact revision; and
- personal revisits and deadline jumps are overlays, not course mutations.

The lab's object types and algorithms are illustrative. They are not a
production schema. In particular, the two-item alternative case does not earn
general AND/OR or hypergraph semantics.
