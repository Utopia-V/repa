# Learner Goal authority

Changes in this subtree must preserve the separate Goal authority recorded by
[Gate 16](../../../../docs/research/opencode-fork-gate-16-learner-goal-authority-2026-07-21.md).
Its 2026-07-30 Agent-native correction supersedes labelled historical
candidate/confirmation and phrase-validation paths while preserving their
stored replay truth.

## Required boundary

Own Goal identity, immutable complete revisions, intended outcome, optional
conditions, LearnerHome/Course scope, structured target time, lifecycle
disposition, one-to-one supersession, exact semantic effect/address,
acknowledgement data, correction, and bounded reads. Goal is not learner
ability/evidence, a todo, Assignment, planning demand, allocation, current
Turn intent, or generic Agenda state.

The ordinary Agent owns open interpretation of whether intent is durable,
which Goal it denotes, and whether it continues, corrects, resumes, replaces,
or begins a distinct purpose. The program owns closed command shapes, exact
heads/CAS, generated identity, trusted time-zone arithmetic, Course scope
revalidation, legal transitions, permission, atomicity, replay, recovery, and
visible correction. Do not reintroduce phrase lists, source-entailment checks,
learner-entered IDs, exhaustive candidate proof, or a second confirmation
protocol.
