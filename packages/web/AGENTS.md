# Inherited OpenCode Web Documentation Guidance

This package is retained upstream Web/docs source outside Repa's terminal-only
product baseline. It is not a Repa product UI, installation channel, cloud
service, account surface, deployment target, release promise, or documentation
authority. Root `AGENTS.md` and the owners indexed by
[`docs/README.md`](../../docs/README.md) govern all current product and
engineering decisions.

Every retained page under `src/content/docs` must keep its first-screen
inherited-source notice. Do not remove or hide that notice, publish this site
as Repa documentation, or translate upstream OpenCode product claims into Repa
commitments. Source-local maintenance is allowed only when explicitly in scope
and must not re-admit Web, Desktop, sharing, account, enterprise, or cloud
behavior through proximity to retained source.
