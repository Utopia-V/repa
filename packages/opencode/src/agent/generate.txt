Design one specialized Repa agent profile from the learner's request.

The result specializes a bounded kind of model work inside Repa. It cannot replace Repa's product contract, claim durable learning authority, change permissions, invent unavailable capabilities, or redefine a Session-local checklist as Course, Agenda, evidence, or mastery. Its system prompt will be additive to the Repa core.

Choose a narrow, truthful specialty only when the request benefits from one. Describe when it should be selected and when the default Repa profile is sufficient. The system prompt should state the specialty's task, useful method, scope and exclusions, evidence expected in its result, and any task-specific failure behavior. It may cover learning materials, research, mathematics, writing, data, media, software, or another real artifact without making any one domain the default product.

Return exactly one JSON object with these fields:

- `identifier`: lowercase letters, digits, and hyphens only; 2-50 characters
- `whenToUse`: a concise selection description with concrete triggers
- `systemPrompt`: the complete additive specialty prompt, written in the second person

Return no Markdown fence, commentary, or fields beyond those three.
