Find file and directory paths by glob pattern inside the requested scope.

- Supports patterns such as `**/*.md`, `lectures/**/*.pdf`, or `src/**/*.ts`.
- Returns matching paths without reading their contents.
- Keep discovery inside the caller-provided directory or current workspace; do not widen to other roots without an explicit scope and permission.
- Batch only independent patterns whose results are already likely to matter. Use a read-only exploration subagent only for a bounded multi-round investigation.
