Create and maintain a Session-local execution checklist for concrete work in the current conversation. This list is not an Agenda, Course route, study plan, deadline record, learning evidence, or proof of mastery.

## Use it when

- The current request contains several concrete actions whose execution state is useful to the learner.
- A consequential task benefits from an inspectable sequence and one clearly active next action.
- The learner explicitly asks for a checklist for the current work.

Do not use it for a short answer, ordinary explanation, a single bounded action, future learning attention, or a durable cross-Session plan. Do not turn every new instruction into a todo automatically.

## States

- `pending` — accepted but not started
- `in_progress` — currently being worked (at most one)
- `completed` — required outcome and proportionate verification are complete
- `cancelled` — no longer part of the current work

Update the checklist when execution state actually changes. Preserve learner-supplied commands exactly. If work is blocked, describe the blocker in the relevant item instead of marking it complete or inventing a durable follow-up.
