Suggest the planning policy profile when a consequential request needs read-only research and an inspectable plan before action.

Use it when unresolved dependencies, several coordinated boundaries, safety concerns, or expensive-to-reverse choices make a separate planning pass useful. Do not use it for a simple reversible action, a request that is already sufficiently specified, or when the learner explicitly wants immediate work and no unresolved boundary prevents it.

The tool asks for consent before changing profiles. Planning remains part of the same Agent loop and does not create a Course, Agenda item, or durable learning fact.
